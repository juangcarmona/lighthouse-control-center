## Responsibility

Explain delivery, quality, autonomy, resource and cost measurements and comparable historical trends from attributable evidence.

## Language

Measurement definition, source, coverage, sample, window, formula, limitation and applicability.

## Boundaries

Lighthouse owns shared engineering and evidence contracts. This context neither changes those rules nor manufactures values or a universal maturity score. Production outcomes require production evidence.

## External Relationships

Consumes fleet configuration, repository delivery evidence, runtime telemetry and provider usage reports. Each calculation retains links to its inputs and governing definition.
