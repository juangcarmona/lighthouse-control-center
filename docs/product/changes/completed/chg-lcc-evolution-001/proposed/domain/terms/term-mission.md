## Definition

Issue-centric work with an intended deliverable, dependencies, acceptance criteria and complete source-correlated delivery history. Its stable issue identity survives repeated execution attempts and repository renames.

## Distinguish From

An execution attempt may succeed while the mission remains blocked, unaccepted or undelivered. A work unit may be one bounded part of a mission.

## Usage

Mission views preserve GitHub issue state, Lighthouse stages, approvals, checks, integration and delivery outcomes separately.
