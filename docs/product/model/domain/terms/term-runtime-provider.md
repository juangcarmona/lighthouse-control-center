## Definition

An independent authority for a declared execution environment, exposing a versioned set of observation and administration capabilities.

## Distinguish From

A provider is neither a pool, a machine, a GitHub runner nor a workflow scheduler. A model provider supplies inference and has a separate authority.

## Usage

Provider capabilities determine which observations and commands Control Center can support.
