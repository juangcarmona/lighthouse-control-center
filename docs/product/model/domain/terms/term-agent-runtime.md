## Definition

The independently operated engine or process environment that executes a bounded agent invocation.

## Distinguish From

The runtime consumes a harness and inference services; it does not own the harness, delivery gates or inference provider billing.

## Usage

Execution observations record the runtime and session identity when evidence supplies it.
