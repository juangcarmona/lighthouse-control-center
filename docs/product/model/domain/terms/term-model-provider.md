## Definition

An inference service authority reporting supported models, availability and attributable usage or billing where available.

## Distinguish From

Requested model configuration does not prove the provider identity, executed model or billed cost.

## Usage

Diagnostics and cost views preserve provider-reported provenance and incomplete attribution.
