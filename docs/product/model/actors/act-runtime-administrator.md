## Purpose

Administer named runtime resources through supported provider operations.

## Goals

Maintain available, bounded execution infrastructure without becoming a repository scheduler.

## Responsibilities

Review target, impact, provider capability and current state; explicitly authorize bounded maintenance or capacity changes; inspect the actual provider outcome.

## Boundaries

Runtime grants are scoped independently of GitHub and sign-in. They do not approve product changes, missions, merges or deployments. Unsupported actions remain unavailable.
