# Design context

This file is an adapter for Impeccable, not a design system. Read the
[Lighthouse design guide](../../docs/design/DESIGN.md), its package-owned tokens,
and the [Control Center visual contract](../../docs/design/control-center.md)
before designing or reviewing the workspace. Those sources own the visual
system and product composition; this file records no independent palette, tokens
or components. Follow the [Impeccable integration guide](../../docs/design/impeccable.md)
for context ownership and verification.
