Sources and limits

Host evidence reads configured registration metadata and committed files only. Registrations do not prove a running process. GitHub runner IDs are scoped to their repository; unmatched runners have unknown physical location. Each GitHub read covers the first 100 runners with source totals. Process health, available capacity, leases, cost, tokens and storage usage are unobserved. Refresh is explicit; observations retain their collection time.
