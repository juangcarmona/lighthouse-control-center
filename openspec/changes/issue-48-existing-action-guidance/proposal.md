# Explain an existing issue action after a changed draft

Tracking: [Lighthouse Control Center #48](https://github.com/juangcarmona/lighthouse-control-center/issues/48).

When the journal returns an existing action for a new prepare attempt, explain that the new draft was not prepared and the existing intent remains unchanged. Point to “Recover previous action” to review the existing action's current status and available next step. Keep the editable draft in the composer.

This is a UI explanation of existing source-backed journal behavior. It does not change product policy, the accepted action model, journal state, request identity, source authority, source operations, or the human confirmation boundary.
